RETURN ELIGIBLE

Order NS1001

Complete these steps to prepare the item for the demonstration return pathway.

1
Keep the product and accessories together.
Make sure the item is complete and ready for inspection.
2
Photograph the product.
Take clear photographs showing the product and its condition before packaging.
3
Package the item securely.
Use suitable packaging to protect the item during the return journey.
4
Include the order reference.
Write or place NS1001 inside the package so the return can be identified.
5
Attach the demonstration return label.
For this MVP, the label step represents the hand-off to the return carrier.
6
Hand the package to the designated return carrier.
Keep your hand-off confirmation for your records.
7
Keep your return reference.
Use it to check the return status after the hand-off.
